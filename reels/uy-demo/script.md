# Демо: дуплекс на улице Махтумкули (система субтитров layered)

- Цель: демо новой системы субтитров «за спиной» на видео владельца
- Язык: uz
- Длина: ~6 сек (видео владельца, 7 слов)
- Кодовое слово: нет

## Текст для генерации аватара
Mahtumquli ko'chasida joylashgan novastroykadan dupleks xonadon ko'rsatamiz.

## Перевод для владельца (ru)
Покажем двухуровневую квартиру в новостройке на улице Махтумкули.
