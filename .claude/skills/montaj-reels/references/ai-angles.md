# Догенерация ракурсов: фото владельца → кадр → раскадровка → видео Wan 3.0

Метод владельца (2026-10-19): если для ролика не хватает ракурса, берём **2–3 настоящих фото этого объекта**, делаем из них
кадр нужного ракурса, **сначала раскадровка и промпты на проверку**, и только потом видео через **Wan 3.0** (Higgsfield).
Близкий проверенный метод для целого ролика — скилл «СОЗДАТЬ ВИДЕО ЧЕРЕЗ ФОТО» (`video-cherez-foto`): его правила точности
объектов и промпты Nano Banana действуют и здесь.

## 0. Нерушимые правила
1. **Только настоящий объект.** Сгенерированный ракурс показывает ту же комнату: та же мебель, её место, материалы, цвет,
   количество окон/дверей/светильников, тот же вид из окна. Ничего не добавлять и не «улучшать» (ни мебели, ни ремонта, ни вида).
   Риелтор продаёт доверие: AI-кадр, который приукрашивает квартиру, — это обман покупателя.
2. **AI дополняет, а не заменяет.** Не больше ~⅓ ролика. Доказательства (вид из окна, состояние ремонта, санузел, подъезд) —
   по возможности настоящие кадры. Если зоны нет ни на одном фото — не выдумывать: попросить доснять или вырезать шот.
3. **Сначала план, потом деньги.** Раскадровка + промпты + цена → владелец говорит «да» → генерация. Повторный запуск — тоже с «да».
4. **Каждый кадр и каждое видео сверять** с фото владельца глазами (§6). Брак не ставить в ролик.

## 1. Когда догенерировать
- комната есть только на фото, видео нет;
- видео есть, но кусок испорчен (тряска, смаз, оператор в зеркале), а ракурс нужен для маршрута;
- не хватает **заготовки для склейки**: начало/конец поворота (`whip`), проход в дверь (`push`), выход из-за стены (петля);
- не хватает **хука**: эффектного первого плана в движении (облёт гостиной, подъём к люстре, вид из окна).
Не догенерировать: то, что владелец может доснять за 5 минут, — дешевле и честнее попросить (памятка `tour.md` §1).

## 2. Шаг 1 — инвентарь и карта пробелов
1. Все фото и видео владельца → по комнатам (`tour-ingest`, `tour-scan`, листы кадров).
2. Мастер комнаты — самое широкое, резкое фото с правдивым цветом; плюс 1–2 фото других углов/деталей.
3. **Инвентарь объектов** комнаты: `объект · где стоит (стена, соседи, порядок) · материал/цвет · количество · лучшее фото`.
4. **Карта пробелов** по плану ролика: `шот · комната · зачем (хук / маршрут / переход) · длина в ролике · какие фото есть`.

## 3. Шаг 2 — кадр нужного ракурса (Nano Banana Pro)
- Модель `nano_banana_pro`, `resolution: 2k`, 9:16; на кадр — 2–3 фото: мастер + вырезки ключевых объектов (≥1000 px).
  Перед работой загрузить скилл `nano-banana-pro-prompting`; шаблоны «Р0 / Р2 / апскейл» — в `video-cherez-foto` §8.
- Камера кадра — **как в нашем стиле**: сверхширокий ~16 мм (0.5x), высота груди, чуть вверх (виден потолок со светом), вертикали ровные.
- Для перехода `push`/прохода в дверь нужны **два кадра**: старт (у двери) и финал (внутри комнаты) — из настоящих фото обеих зон.
- Сверка кадра с фото по инвентарю (§6): форма, место, цвет, количество. Расхождение — переделать, не идти дальше.

## 4. Шаг 3 — раскадровка (показать владельцу до генерации)
Одна картинка-лист + таблица (artifact или файл). На каждый AI-шот карточка:
| Поле | Пример |
|---|---|
| № и место в ролике | AI-2 · 4,5–7,0 с · после кухни, перед спальней |
| Зачем | хук / маршрут / заготовка под `whip` / вход через `push` |
| Исходные фото | P03 (мастер гостиной), P07 (диван), P11 (люстра) |
| Стартовый кадр (+ финальный) | миниатюры сгенерированных кадров |
| Движение камеры | **одно**: медленный облёт влево вокруг стола, 4 с |
| Длина генерации | 4–6 с (короче — меньше «плывёт») |
| Склейка с соседями | конец — резкий поворот вправо под `whip` |
| Промпт Wan 3.0 | полностью, по формуле §5 |
| Модель и цена | `wan3_0`, 1080p, 5 с — N кредитов |
Внизу — итог: сколько шотов, сколько кредитов всего. Ждать «да» (или правки) по каждому шоту.

## 5. Шаг 4 — видео Wan 3.0
**Модель:** `wan3_0` (обычно) или `wan3_0_prime` (хук/кульминация). Параметры: `aspect_ratio: "9:16"`, `resolution: "1080p"`,
`duration` 4–6 (2–30 можно, но длинное сильнее «плывёт»), **`generate_audio: false`** (музыка своя), `enable_thinking: true`
(лучше слушается промпта). `medias`: `start_image` — кадр шага 2; для прохода в дверь / точной траектории — ещё `end_image`.
По обзорам, первый/последний кадр нельзя совмещать с `image_references` — не смешивать режимы.

**Формула промпта** (кадр уже задаёт комнату и стиль — промпт описывает **только движение и что неизменно**):
```
[Камера: один глагол + скорость + траектория]. [Что открывается к концу движения — только видимое на фото].
Keep the room exactly as in the first frame: same layout, furniture, materials, colors, window view and light; walls and verticals stay straight and rigid.
Smooth gimbal motion, ultra-wide 16 mm lens at chest height, real-estate walkthrough, natural daylight.
No people, no text, no new objects, no morphing.
```
**Готовые движения** (подставлять в первую строку):
| Нужно | Первая строка |
|---|---|
| хук-облёт | `The camera slowly arcs to the left around the coffee table, keeping the sofa in the center, parallax on the floor lamp in the foreground.` |
| проход вперёд | `The camera glides slowly forward into the room at walking pace, level, no rotation.` |
| вдоль кухни | `The camera slides slowly sideways to the right along the kitchen island, parallel to the counter.` |
| к люстре | `The camera tilts slowly up from the dining table to the chandelier and holds.` |
| отъезд-раскрытие | `The camera pulls back slowly from the window, revealing the whole bedroom.` |
| дверь (старт+финал) | `The camera moves forward through the doorway from the first frame and ends exactly on the last frame inside the room.` |
| заготовка под whip | `The camera holds for two seconds, then pans sharply to the right with strong motion blur.` |
Наречия управляют скоростью (`slowly`, `gently`, `sharply`); без явного движения модель придумает своё — **всегда называть движение**.

**Загрузка кадров в Higgsfield:** `media_upload` → PUT файла → `media_confirm`; если из облака не доходит — `media_upload_widget`.
Перед генерацией — цена (preflight) и «да» владельца; партию — `generate_video_batch`, ждать `jobs_wait`.

## 6. Шаг 5 — сверка (смотреть самому)
- Кадр шага 2: каждый объект инвентаря — та же форма, место, материал, цвет, количество; вид из окна тот же.
- Видео: листы кадров каждые 0,25 с (`tour-scan` по файлу) + глазами начало/середину/конец.
  Брак: стены гнутся или «дышат», мебель меняет форму/количество, появились люди/текст/лишние предметы, мерцание,
  движение не то или слишком быстрое, вид из окна другой.
- Брак → один повтор: короче `duration`, проще движение, добавить `end_image`. Снова брак → запасной вариант: настоящий кадр
  с плавным наездом (Ken Burns, `push` 0.06–0.1) или просьба доснять. Сказать владельцу честно, что не получилось.

## 7. Шаг 6 — в монтаж
- Видео → `npm run tour-ingest` вместе с настоящими клипами (AI-клипы 720/1080p приводятся к 1080×1920).
- AI-клип ставить между настоящими; его начало и конец прятать в переходы (`whip`, `dissolve`, `wall`) — так не заметен стык стилей.
- Скорость AI-клипов обычно 1–1.3; `grade` общий на весь ролик выравнивает цвет. Если AI-кадр заметно «другой» по цвету — `warm`/`cool` под настоящие.
- В `PROGRESS.md` — какие шоты сгенерированы, из каких фото, сколько кредитов.
