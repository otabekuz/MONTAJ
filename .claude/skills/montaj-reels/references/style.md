# Фирменный стиль обзоров: сильное из 7 образцов владельца

Владелец прислал 7 роликов-образцов (2026-10-19) и попросил взять сильные стороны **каждого** и монтировать так всегда.
Покадровый разбор образцов — `docs/tour-reference.md`. Как это собирается технически — `tour.md` (без речи) и `elements.md` (с ведущим).
Если ракурсов не хватает — `ai-angles.md` (догенерация через Wan 3.0).

## 1. Что берём из каждого образца
| Образец | Сильная сторона | Как делаем у себя |
|---|---|---|
| **A** облёт гостиной | объём: предмет на переднем плане (торшер) проходит у объектива, пока камера облетает стол | съёмка: облёт по дуге **с предметом впереди**; монтаж: медленный финал-«посадка» на общем плане |
| **B** гостиная → кухня | схема «плавно 1–1,5 с → резкий поворот 0,2–0,3 с», все повороты в одну сторону | Tour: `whip` (сам разгоняет края) + базовая `speed` 1.3–1.6 |
| **C** вся квартира | маршрут как идёт гость; склейки — наплыв в движении и дверь у объектива; финал на двери | Tour: `dissolve`, `wall`, `cut` на настоящей шторке; порядок комнат |
| **D** быстрый тизер | смена кадра каждые 1–2 удара, пролёт в главную комнату **ровно на дроп**, петля | Tour: `beatSync`, один `push` на сильную долю, `loop` |
| **E** ведущая у дома | хук: огромные тонкие слова **за спиной**; дрон с текстом в пейзаже; серии вставок 0,7–1,2 с под слова; ведущая меняет позу (стоит → сидит) | Reel full + «Серебро» (`giant`), серии `broll` с `cut`; дрон — если есть материал |
| **F** «Хороший ремонт — дорого» | **текст на поверхностях** (дверь, фасад), **рулетка** высоты потолка, переход «окошко», **два кадра стопкой**, макро-детали, сцены жизни, тёплый кино-цвет, финал «Подробности у меня» | `surface`, `ruler` (и в Reel, и в Tour), `inset`, `stack`, `grade: warm` |
| **G** «No, I'm not AI…» | хук-парадокс; **сначала локация** (озеро, гольф, клубный дом) с крупным названием района, потом дом; финал — дрон сверху | хук-вопрос в сценарии; `location` / `districts` / дрон в начале; финал-общий план |

## 2. Два формата одного стиля
| | **Обзор без речи** (A–D) | **Обзор с ведущим** (E–G) |
|---|---|---|
| Когда | есть только клипы объекта; тизер для ленты; объект говорит сам | владелец в кадре; нужно доверие, цена, условия, район |
| Композиция | `Tour` (`"layout": "tour"`) | `Reel` (`"layout": "full"`, субтитры «Серебро») |
| Длина | тизер 10–18 с, проход 25–45 с | 30–60 с |
| Ритм | клип 0,8–4 с, склейки на удары | ведущий 2–3 с → серия 3–6 вставок по 0,7–1,2 с под слова → ведущий |
| Звук | только музыка | голос + музыка тише голоса |
| Текст | по умолчанию нет; тихие подписи, `surface`, `ruler` | «Серебро» (гигант за спиной + слова), `surface`, `ruler`, `chip` |

## 3. Правила, общие для обоих форматов
1. **Хук за 1–2 с**: кадр уже в движении + одна сильная мысль (самый эффектный план, слово за спиной, надпись на двери, парадокс).
2. **Кадр всегда меняется**: в обзоре — движение камеры; с ведущим — новая вставка каждые 0,7–1,2 с, ведущий не дольше 3 с подряд.
3. **Склейки спрятаны**: поворот со смазом, предмет у объектива, наплыв, пролёт; «окошко» и стопка — редкие акценты (1–2 раза).
4. **2–3 приёма на ролик**, повторяются; не всё сразу. Например: `whip` + `dissolve` + один `push`; или «Серебро» + серии вставок + один `surface` + один `ruler`.
5. **Факты — в пространстве, а не плашкой**: площадь и этаж на двери/стене (`surface`), потолок рулеткой (`ruler`), этажность на фасаде. Только реальные данные владельца.
6. **Детали крупно**: фактура стены (рука по ней), фурнитура, свет люстры, мрамор, паркет — по 0,7–1 с между общими планами.
7. **Сцены жизни** (F): человек читает у окна, садится на кровать, смотрит на вид — зритель «примеряет» себя.
8. **Сначала локация, если она сильная** (G): вид, парк, набережная, район крупно — потом квартира.
9. **Порядок как идёт гость**: локация/подъезд → гостиная → кухня → коридор → санузел → спальни → вид/терраса.
10. **Кульминация на сильную долю музыки**: лучшая комната через `push` (D) или главный факт через `surface`/`giant`.
11. **Финал**: лучший общий план или ведущий + одна короткая фраза («Подробности у меня», кодовое слово); в обзоре без речи — петля.
12. **Цвет**: светло и чисто (`clean`) — по умолчанию; тёплые интерьеры, дерево, вечер — `warm` (E, F); стекло, бетон — `cool`. Без тяжёлых фильтров.
13. **Звук**: без whoosh; музыка выбирается до монтажа; склейки на ударах.

## 4. Чек-лист «как в образцах» перед отправкой
- Первые 2 с: движение + сильная мысль; без чёрного кадра и «здравствуйте».
- Нет пауз: ни один план не стоит дольше 3 с без движения.
- Склеек не видно (смаз / предмет / наплыв / пролёт) или они в ритме музыки.
- Есть минимум одна деталь крупно и одна «сцена жизни» (если есть материал).
- Факты — в пространстве и только реальные; цена — только от владельца.
- Порядок комнат как у гостя, кульминация на сильную долю, финал — общий план или призыв.
- Нет ошибок материала: оператор в зеркале, бардак, заваленный горизонт, «выгоревшие» окна (см. `tour.md` §2).
