# Анимации и элементы монтажа

> Сгенерировано из `.claude/agents/reel-editor.md` командой `npm run pack-skill`. Правь источник, не этот файл.

Каталог всего, что можно поставить в ролик. Точный формат полей — `schema.ts` рядом (копия `src/Reel/schema.ts`), заполненный план — `example-edit.json`. Как из этого собирать ролик — `montage.md`.

## Шаблон edit.json

```json
{
  "layout": "full",
  "lang": "uz",
  "palette": "sky",
  "videoFile": "reels/<slug>.mp4",
  "captionsFile": "reels/<slug>.captions.json",
  "fallbackSeconds": 30,
  "cutPauses": true,
  "speed": 1,
  "beats": [],
  "cues": [],
  "hook": "…",
  "hookSeconds": 2.8,
  "highlightWords": ["…"],
  "autoFraming": true,
  "zooms": [],
  "transitions": [],
  "overlays": [],
  "sfx": true,
  "musicFile": "",
  "cta": "",
  "ctaSeconds": 2.6
}
```

Заготовку создаёт `npm run new-reel -- <slug> <full|split|voice> <uz|ru>`.

## Каталог элементов (`overlays`)
| type | когда | `dur`, сек |
|---|---|---|
| `title` `{text, sub}` | начало смыслового блока: 1–3 слова крупно (`text`), маленькая акцентная метка сверху (`sub`, напр. «01», «xato», «ошибка») | 1.3–2.0 |
| `property` `{title, price, place, image, specs: [{icon, label}]}` | **объект-герой**: карточка квартиры/дома — фото (`image` — файл в `public/reels/<slug>/`, "" — схематичный дом), цена «металлом», район, до 4 параметров-чипов (`rooms` «3 xona», `area` «78 m²», `view` «7/9 qavat», `parking`, `bath`, `repair`…). **Только реальные данные объекта** | 3.0–5.0 |
| `districts` `{focus: [{id, rank?, value?, at?}], zoom?, objects?, title?}` | **карта районов Ташкента (схема) — герой роликов о локациях и ценах.** `focus: []` — «поиск»: сканер и «?» (под хук). Иначе районы подсвечиваются заливкой и светящейся обводкой, `at` — секунда, когда звучит название района (без `at` — сразу по очереди); `rank` — номер 1–12 в кружке; `value` — подпись «металлом» (**только реальная цифра**); `zoom: true` — наезд камеры на выбранные районы; `objects`: `"towers"` (растут многоэтажки — квартиры) или `"houses"` (частные дома) на первом районе; `title` — плашка сверху («Квартиры · цена м²»). До первого `at` по карте идёт сканер — «ищем». id: `shayxontohur, olmazor, yunusobod, mirzoulugbek, yashnobod, mirobod, yakkasaroy, chilonzor, uchtepa, sergeli, bektemir, yangihayot`. Повторяй карту через ролик с разными состояниями — это и есть герой | 3.0–6.0 |
| `giant` `{text, pre?, color?, italic?, y?}` | **слово-гигант за спиной** (система layered, нужен `subjectFile`): огромное слово на уровне головы, человек стоит перед ним. `color`: `metal` / `accent` / `white`; `pre` — приставка курсивом (только из речи); `y` — центр по высоте 0..1 (по голове, обычно 0.27–0.33). Буквы проявляются слева направо, уходит в размытие. Слово ≤ 12 букв | 1.2–2.5 |
| `chip` `{icon, text, y?}` | **метка сверху** (над головой): 📍 улица, 🏢 «Novostroyka», этажи — короткий текст из речи; печатается, по ней бежит блик. Не размывает спикера. Можно сменять одну за другой | 0.9–2.5 |
| `tg` `{mode, title, sub?, messages?, posts?, search?, lines?, button?, tapAt?}` | **телефон с Telegram — герой роликов про бота и канал** (макет интерфейса). `chat`: `messages` — `{from: user/bot, at, text?, typeDur?, chips?: [{text, icon, at?}], cards?: 1–3, note?}`; сообщение пользователя печатается `typeDur` с от `at` синхронно с голосом и отправляется; бот «печатает…» и отвечает; чипы — разобранные параметры запроса (по словам), карточки — иллюстрации квартир. `channel`: `posts` `{author, title, tag}` листаются, `search` `{text, at, match}` — поиск, остаются посты `match`. `start`: экран бота, `lines` — 2–3 преимущества, кнопка `button` и нажатие в `tapAt`. Названия бота и канала — **настоящие**; если владелец прислал скриншоты — вставь их `screen` | 2–17 |
| `feed` `{label?, aiAt?}` | **«листаете сотни объявлений»**: в телефоне летит лента серых карточек, палец свайпает; в `aiAt` включается ИИ-ядро, лента тормозит, сканер находит элитные квартиры (свечение, галочка). Отличный хук | 4–7 |
| `notify` `{items: [{at, title, text, time?}], heroAt?, heroLabel?, clock?}` | **уведомления**: экран блокировки, в `heroAt` вспыхивает новая квартира с меткой, в `items[].at` падают уведомления Telegram (≤ 3). Для «бот сам присылает» | 4–7 |
| `days` `{label?, strikeAt?}` | **«каждый день заново»**: неделя, в каждом дне вспыхивает поиск, в `strikeAt` неделя перечёркивается, `label` — вывод («Не нужно») | 2.5–4 |
| `location` `{place, sub}` | называют район/ориентир: на условной карте падает метка, подпись района (`place`) и ориентира (`sub`, напр. «metroga 5 daqiqa» — только если сказано) | 2.5–4.0 |
| `number` `{value, suffix, label, prefix?}` | **только реальная цифра из речи**: крупная «металлическая» цифра со счётчиком, как «$17 M» на образце (`prefix` "$", `suffix` "M", "m²", "%", "kun") | 3.0–3.5 |
| `clones` `{labels, marks?}` | **герой «все объявления одинаковые»**: три одинаковых серых типовых объявления. `labels` — подписи (≤ 2 слова: «Qorong'i rasm», «Narx yo'q»), `marks` — доли длительности (0..1), когда подпись появляется | 3.5–7.5 |
| `morph` `{before, after}` | **герой меняется**: типовое объявление превращается в премиальное (линия-сканер в середине элемента). Ставь так, чтобы середина пришлась на слова о результате | 4.0–5.5 |
| `tool` `{name, icon}` | называют сервис/приложение (OLX, Uybor, Telegram, банк). icon — ключ из списка ниже или `file:<png в public/logos>` | 1.4–2.0 |
| `chat` `{prompt, answer}` | переписка с клиентом/запрос; печатается сообщение. `answer` — только дословно со скриншота, иначе "" | ≈ len(prompt)/34 + 1.3 |
| `steps` `{title, items}` | перечисление 2–4 пунктов (≤ 4 слова каждый): документы, шаги сделки | ≈ 0.4 + 0.85·n + 2.0 |
| `screen` `{title, image, zoomTo?, frame?}` | скриншот (объявление на OLX, карта, документ). `frame`: `"phone"` (вертикальный) или `"window"` (горизонтальный). `zoomTo {x,y,w,h}` — через 1 с наезд на область + рамка; доли самого скриншота (открой картинку через Read и оцени). **Если на скриншоте есть конкретная цена/кнопка/фраза — всегда zoomTo** | 3.0–5.0 (с zoomTo ≥ 3.5) |
| `broll` `{file}` | есть видео/фото владельца по теме (`reels/<slug>/…`): подъезд, кухня, вид из окна. Без файла — не используй | 2.0–4.0 |
| `accent` `{text, emoji}` | ударная фраза/вывод, 1–3 слова; слово падает с ударом и тряской | 1.5–2.0 |
| `icon` `{items: [{icon, label}]}` | **визуальная метафора** мысли: 1 иконка крупно или 2–3 в ряд («vaqt, pul, natija» / «время, деньги, нервы») | 1.8–3.0 |
| `compare` `{bad, good, badLabel, goodLabel}` | «все делают так — а надо так», до/после. Тексты ≤ 12 слов; метки `Yomon`/`Yaxshi`, `Oldin`/`Keyin` или `Плохо`/`Хорошо`, `До`/`После` | 3.5–5.0 |
| `flow` `{nodes: [{label, icon}]}` | процесс из 2–4 шагов (A → B → C), последний — результат (акцент): «Rasm → Narx → Sotildi» | ≈ 0.15 + 0.75·n + 1.8 |
| `chart` `{title, unit, bars: [{label, value, highlight}]}` | сравнение величин из речи — **только реальные цифры**; 2–4 столбика | 3.5–4.5 |
| `typed` `{text, em}` | тезис **набирается по словам** со свечением; слова из `em` — акцентный курсив с засечками: «Gap narxda emas» (em: «emas»). ≤ 5 слов | 1.5–2.6 |
| `slam` `{text, em}` | **смена мира: весь кадр заливается акцентом**, одно огромное слово (≤ 9 букв) + приписка курсивом. Главный удар ролика — **ровно один раз**. Субтитры на время slam скрываются. `riser`-cue упирается в начало | 1.5–2.0 |
| `paper` `{tag, title, items: [{text, mark}], times?}` | **смена мира: светлый бланк** с пунктами (2–5, по 1–2 слова); `mark`: `"v"` — галочка, `"x"` — зачеркнуть, `""` — пусто. `times` — секунды исходника, когда появляется каждый пункт (по словам; без них — каждые 0,9 с). Чек-листы, перечисления сегментов. Не чаще 1–2 раз | ≈ 0.5 + 0.9·n + 0.8 или до последнего слова + 1 |
| `hub` `{center, items, times?}` | **ядро + модули**: к центру («Цена», «Sizning uy») по очереди подключаются 2–5 модулей (факторы, части), по линиям бежит свет. `times` — секунды исходника для каждого модуля (по словам). Названия ≤ 14 букв | ≈ 0.6 + 0.6·n + 0.8 или до последнего слова + 1 |

**Ключи иконок** (`icon`): недвижимость — `home, apartment, building, newbuild, commercial, warehouse, map, location, area, rooms, bath, parking, deal, contract, family, school, park, metro, bank, mortgage, safe, legal, repair, sun, view, water`; общее — `time, hourglass, calendar, money, coins, wallet, price, sales, growth, chart, levelup, rocket, speed, percent, error, wrong, right, question, idea, brain, ai, magic, wand, chat, write, copy, document, checklist, target, search, filter, settings, puzzle, shuffle, key, lock, eye, person, clients, business, learn, book, phone, laptop, photo, video, voice, language, love, happy, sad, star, trophy, send`. Неизвестный ключ → звёздочки.

**Объект-герой.** Сильный ролик — одна история с одним героем, а не «заголовок → иконка → заголовок». Для недвижимости готовые герои: **карта Ташкента** (`districts`: поиск → район №1 с многоэтажками → топ-3 → другой сегмент с домами), **объявление** (`clones` → `clones` → `morph`), **объект** (`property` в начале и снова в финале с результатом), **цена** (`number`/`chart`), **район** (`location`). Проведи героя через ролик: проблема → ухудшение → решение → результат. Если готового героя нет — повторяй один элемент с изменением (`compare`, `flow`) и напиши в отчёте, какого героя стоит добавить в код.

**Три мира.** Тёмный с сеткой — основной. Заливка акцентом (`slam`) — удар, один раз. Светлая бумага (`paper`) — передышка и перечисление. Смена мира = поворот в смысле; не ставь два «светлых» элемента подряд.

**Показывай смысл, а не каждое слово.** Каждая ключевая мысль (раз в 3–4 с) получает визуальную метафору: сравнение → `compare`, процесс → `flow`, «время/деньги/нервы» → `icon`, величины → `chart`/`number`, объект → `property`, район → `location`. Не иллюстрируй каждое существительное.

`at` — секунда, когда звучит ключевое слово (можно на 0.1–0.2 с раньше). У `districts`, `hub`, `paper` внутренние моменты (`focus[].at`, `times`) тоже ставь по словам — анимация, попадающая в слово, выглядит дороже.

### Поля плана
- Все `at` и `dur` — **секунды исходника**.
- `lang` — `uz`/`ru`; `palette` — `sky` | `champagne` | `sage` | `blush` (выбор владельца — в `PROGRESS.md`).
- `captionStyle` — `layered` (три уровня, по умолчанию для full с вырезкой) или `classic` (две строки внизу); `captionY` — высота строки субтитров (доля кадра); `subjectFile` — вырезка человека; `grade` — цветокоррекция и виньетка.
- `fallbackSeconds` — длина, если файла ещё нет (заглушка); ставь длину исходника.
- `hookSeconds` — сколько секунд исходника держится хук; обычно до конца первой фразы (2–3.5).
- `cta` — текст плашки с кодовым словом ВЕРХНИМ РЕГИСТРОМ (оно подсветится): «Izohga UY deb yozing». Пусто — плашки нет.
- `highlightWords` — сравниваются без регистра и пунктуации, целым словом: пиши словоформу как в субтитрах (`narxda`, а не `narx`).
- `zooms`: `{at, dur, scale}`; `transitions`: `{at, type}`; `cues`: `{at, sound, volume}`.
- `musicFile` — своя музыка проекта: `music/montaj-calm.webm` (советы, разборы, спокойные истории) или `music/montaj-pulse.webm` (динамика: боты, подборки, «до/после»); другая — только лицензионная из `public/music/`. По умолчанию ставь одну из своих; пусто — без музыки.
- Диапазоны `dur` — ориентир. Если фраза короче — сокращай (не меньше ~1.0 с) и упрощай текст, а не налезай на следующий элемент.

### Тонкости элементов
- `property`: цена и параметры — только из речи или данных владельца; нет фото — `image: ""` (схематичный дом), не подставляй чужие фото.
- `steps`: пункты появляются каждые 0,85 с. Если в речи пункты идут реже (> 1,2 с между ними) — вместо `steps` отдельный `title` на каждый пункт с `sub` «01», «02»…
- `compare`: «плохая» карточка сразу, перечёркивается через ~0,5 с, «хорошая» — через ~1 с.
- `number`: в full — главная цифра ролика, как на образце; не больше 1–2 раз.
- Устный призыв без кодового слова («Saqlab qo'ying») можно поддержать `accent` или `icon`; плашка `cta` — только для кодового слова.

## Переходы (`transitions`) — на границах смысловых блоков
- `smear` — **смаз**: полосы света пролетают через кадр. Основной переход между блоками, мягкий — можно 3–5 на ролик;
- `flash` — вспышка на «раскрытии» (цифра, результат, вывод);
- `wipe` — шторка, перед блоком ценности/шагов;
- `whip` — пролёт, универсальный;
- `glitch` — максимум 1 на ролик, как pattern interrupt;
- `leak` — засветка: тёплое пятно света проплывает через кадр (беззвучно). Для живого видео — в начале и на смене мысли.
Ориентир — один переход на 8–10 с ролика. `whip` не ставь ближе 0.5 с к началу `accent`. В split переходы идут только в верхней половине.

## Звуковые акценты (`cues`) и тишина (`beats`)
- `cues: [{at, sound, volume}]` — `riser` **заканчивается** в `at`, остальные (`impact`, `shine`, `glitch`, `pop`) стартуют в `at`. Громкость 0.25–0.45. **Whoosh не используем.** Графика и переходы озвучены сами — cues только для драматургии:
  - `riser` → в кульминацию (главный вывод, `accent`, `number`) — 1 раз на ролик;
  - `impact` на самом сильном слове без графики — максимум 1–2.
- `beats: [сек]` — «тишина перед главной мыслью»: пауза перед этим словом не вырезается (до 0.7 с), музыка затихает. **0–1 раз на ролик.** Во время тишины — никаких звуков и новых элементов; сразу после — `accent` или `title`.

## Приближения (`zooms`)
`autoFraming: true` уже меняет план на каждой фразе. Явные `zooms` (scale 1.1–1.2, dur 0.8–1.5) — только на 1–3 самых сильных словах.
