# Обзор объекта (формат Tour): съёмка, разбор, монтаж

Формат для роликов **без речи**: владелец снял квартиру/дом на телефон, ролик — проход «одним дублем»
под музыку, склейки спрятаны в движении. Образцы и покадровый разбор — `docs/tour-reference.md`.
Код — `src/Tour/` (композиция `Tour`), формат плана — `tour-schema.ts` рядом, пример — `example-tour.json`.

## Содержание
1. Памятка владельцу: как снимать

## 1. Памятка владельцу: как снимать
Отправляй её владельцу, когда он собирается снимать объект (коротко, по-русски):
- **Объектив 0.5x, вертикально, 4K 60 к/с** (iPhone: Настройки → Камера → Запись видео → 4K 60). 60 к/с нужны для плавных ускорений и замедлений.
- **Режим «Экшн» или стабилизатор**; камера на уровне груди, чуть вверх — чтобы был виден потолок со светом. Горизонт ровно.
- **Идти медленно, в 2 раза медленнее обычного шага.** Ускорить можно в монтаже, замедлить рывки — нельзя.
- **Подготовка**: включить ВЕСЬ свет и подсветку, открыть шторы, убрать вещи, провода, обувь, тряпки; закрыть унитаз; никого в кадре.
- **Экспозиция**: долгое нажатие на экран в комнате → фиксация, чуть убавить (окна не должны «выгорать»).
- **Каждая комната — отдельный дубль 6–15 с**: начинать за 1 с до нужного движения и заканчивать через 1 с после.
- **Движения** (каждое — отдельный дубль): облёт вокруг стола/кровати по дуге; проход вперёд; медленный подъём камеры к люстре; проход вдоль кухни боком.
- **Заготовки под склейки** (то, из чего делаются «как в образце»):
  - конец комнаты — **резкий поворот вправо**, начало следующей — тоже резкий поворот вправо (одна сторона, одна скорость);
  - пройти **вплотную мимо дверного косяка или стены** — так, чтобы на миг кадр закрылся;
  - в конце — **наезд в стену/дверь** вплотную; в начале следующей — **отъезд от стены**.
- **Зеркала и стекло**: проверить, что в отражении нет оператора (частая ошибка — даже в образце C на 37,4 с).
- Снять **вид из окна**, подъезд/лобби, двор — это финал или хук.

## 2. Разбор присланного материала
1. `npm run tour-ingest -- <slug> "<папка или файлы>"` — приём (HDR iPhone → обычный цвет, 60 к/с сохраняются).
2. `npm run tour-scan -- <slug>` — отчёт по каждой 0,5 с + лист кадров `out/scan/<slug>-clip-NN.png`. Посмотри листы глазами.
3. Ответ владельцу — **честный разбор, по каждому клипу**: «с–по — что не так — что делаем» (вырезаем / ускоряем / прячем в переход / переснять).
   | Отметка | Что значит | Что делаем |
   |---|---|---|
   | тряска | дёрганье поверх плавного движения | не брать; если кусок нужен — ускорить ≥2× (смаз прячет тряску) или спрятать в whip |
   | нерезко | смаз, грязный объектив, мало света | не брать; объектив протирать перед каждой комнатой |
   | пересвет | «выгоревшие» окна | короткий кусок — терпимо в проходе; на виде из окна — переснять с фиксацией экспозиции |
   | темно | мало света | `grade` не спасает — переснять с включённым светом |
   | стоит | камера не двигается | 1–2 с на детали можно, дольше — выкинуть |
   | рывок | резкий поворот | **готовая точка для whip** — склейку ставить в середину рывка |
   Ещё смотри сам: заваленный горизонт, оператор в зеркале/стекле, люди, беспорядок, открытый унитаз, провода, пятна на объективе, «гуляющий» баланс белого.
4. Переделать самому, если «совсем ужас»: тряску — ускорением и смазом (`ramps` 2.5–4×), пересвет и тусклость — `grade` (clean/warm),
   мягкость — `sharpen`, скучный статичный кадр — `push` 0.05–0.08 (цифровой наезд), лишний кусок — обрезать `in/out`.
   Чего монтаж не исправит (темнота, оператор в зеркале на весь кадр, бардак) — честно сказать и попросить переснять конкретную комнату.

## 3. Как монтировать
### Структура (порядок как идёт гость)
| Часть | Длина (тизер 10–18 с / полный 25–45 с) | Что |
|---|---|---|
| Хук | 0–1,5 с | самый эффектный общий план (гостиная, люстра, вид), **уже в движении** с 1-го кадра; лучше всего — через поворот или выход из-за стены |
| Проход | основная часть | гостиная → кухня → коридор → санузел → спальни → гардероб → ванная |
| Кульминация | 1 раз | лучшее место (вид из окна, мастер-спальня, терраса) — на сильную долю/«дроп» музыки, через **пролёт** |
| Финал | 1–2 с | торможение на красивом общем плане, или наезд в стену/дверь для петли (`loop`) |
- Кадр (кусок клипа) в ролике: тизер — 0,8–1,8 с; полный — 2–4 с. Что-то меняется каждые 1–2 удара.
- Длина: тизер 10–18 с (досматривают и пересматривают), полный проход до 45 с. Длиннее — честно сказать владельцу, что досмотр упадёт.

### Скорость
- Базовая `speed`: проход 1.3–2 (шаг владельца медленный), «вкусная» деталь 0.8–1 (только с 60 к/с), коридор 2–3.
- `ramps` — ускорение участка внутри клипа (2.5–4×): коридоры, повороты, скучные куски. Края сглажены сами.
- whip и push **сами разгоняют** конец клипа и начало следующего до 3× — отдельно `ramps` для этого не нужны.
- `motionBlur: true` всегда — на ускорениях кадры смешиваются, как у настоящей камеры.

### Переходы (`exit` у клипа)
| Тип | Как выглядит | Когда | Образец |
|---|---|---|---|
| `whip` | кадр проносится вбок со смазом, новый прилетает с той же стороны | между комнатами; конец клипа с поворотом; `dir` — куда уходит кадр (камера повернула вправо → `left`) | B, D |
| `dissolve` | наплыв 0,4 с, оба кадра в движении | спокойный переход; движения в одну сторону; внутри одной комнаты | C, A |
| `wall` | у объектива проходит светлая (`tone: light`) или тёмная стена — склейка под ней | проход через дверь, мимо косяка; когда снятой «шторки» нет | C 21 с, D 6,6 с |
| `push` | наезд со смазом в кадр → новая комната выплывает из глубины, вспышка света | **1 раз**: вход в главную комнату/вид — на сильную долю | D 3,6 с |
| `cut` | встык | дверь/стена уже закрыла кадр в самом видео; совпадает движение | C 29,1 с |
- 2–3 типа на ролик и повторять их (например, `whip` + `dissolve` + один `push`). Все `whip` — в одну сторону.
- Если в исходнике есть настоящая «шторка» (дверь у объектива) — `cut` ровно в момент, когда кадр закрыт, это лучше любого эффекта.

### Музыка и бит
- Сначала музыка, потом монтаж. `beatSync: true` сам ставит каждую склейку на удар (меняя скорость клипа в пределах 0.8–1.25×).
- Своя музыка: `music/montaj-pulse.webm` (бодро) / `montaj-calm.webm` (спокойно) — `bpm: 96`, `beatOffset: 0`.
- Трек владельца: положить в `public/music/`, `npm run beats -- music/<трек>` → `beatsFile`. `musicStart` — секунда трека, с которой начинать (дроп/припев).
- `beatEvery`: тизер — 1–2, полный — 2–4.
- Если владелец хочет трендовый звук Instagram: собрать с похожим по темпу треком, а в Instagram заменить звук — темп нужен тот же.

### Текст (по умолчанию — без текста, как в образцах)
- `tags` — тонкая подпись комнаты/факта (не больше 3–4 на ролик): «Oshxona», «Yotoqxona · panorama oyna». Только реальные данные владельца.
- `hook` — короткий хук сверху на 1,5–2,5 с, если владелец просит («3 xonali · Yunusobod»).
- `endCard` — финальная плашка: заголовок + 1–3 строки (цена, комнаты, контакт) — только цифры владельца. С `loop` плашка заканчивается до петли.

### Цвет и качество
- `grade: "clean"` — по умолчанию (светло, чисто, как в образцах); `warm` — тёплые интерьеры (дерево, беж); `cool` — бетон, стекло, мрамор.
- `sharpen: true` — по умолчанию (телефонное видео мягкое). `push` по умолчанию 0.02 (лёгкий наезд оживляет кадр).

## 4. План edit.json для Tour
`npm run new-reel -- <slug> tour <uz|ru>` создаёт заготовку из `reels/<slug>/clips.json`. Поля — `tour-schema.ts`. Основное:
```json
{
  "layout": "tour",
  "clips": [
    { "file": "reels/<slug>/clip-01.mp4", "in": 0.4, "out": 4.2, "speed": 1.4, "exit": { "type": "whip", "dir": "left" } },
    { "file": "reels/<slug>/clip-02.mp4", "in": 1.0, "out": 6.5, "speed": 1.6, "ramps": [{ "at": 3.0, "dur": 1.2, "speed": 3 }], "exit": { "type": "dissolve" } }
  ],
  "musicFile": "music/montaj-pulse.webm", "bpm": 96, "beatOffset": 0, "beatSync": true, "beatEvery": 2,
  "grade": "clean", "sharpen": true, "motionBlur": true, "loop": true, "tags": [], "coverAt": 0.4
}
```
- `in`/`out` — секунды файла клипа; переход **тратит запас** за краями (`dur`/2 с каждой стороны) — оставляй в исходнике ~0,3 с за `in` и `out`.
- Один файл можно резать на несколько клипов (разные `in/out`).
- `loop: true` — `exit` последнего клипа ведёт в первый кадр ролика.
- `coverAt` — секунда обложки (самый красивый общий план).

## 5. Команды
| Команда | Что делает |
|---|---|
| `npm run tour-ingest -- <slug> "<папка или файлы>"` | клипы → `public/reels/<slug>/clip-NN.mp4` (1080×1920, до 60 к/с, HDR → SDR, без звука, ключевой кадр каждые 0,5 с), список — `reels/<slug>/clips.json` |
| `npm run tour-scan -- <slug>` | разбор: тряска, резкость, пересвет, темнота, статичные места, точки для whip → `out/scan/*.txt` и листы кадров `*.png` |
| `npm run beats -- music/<трек>` | темп и удары трека → `public/music/<трек>.beats.json` |
| `npm run new-reel -- <slug> tour <uz\|ru>` | заготовка плана из `clips.json` |
| `npm run check -- <slug> t1 t2 c3 2s` | кадры: `t<k>` — середина k-го перехода, `c<k>` — середина k-го клипа |
| `npm run build-reel -- <slug>` | рендер → −14 LUFS → обложка (`coverAt`) |

## 6. Проверка перед отправкой
- Первый кадр уже в движении и это лучший общий план; без чёрного кадра в начале.
- Каждый переход посмотрен (`check t1 t2 …`): под whip/wall не видно «шва», после наплыва нет двойного изображения дольше 0,5 с.
- Ни одного куска с тряской, нерезкостью, оператором в отражении.
- Склейки на ударах (`beatSync`), кульминация — на сильной доле.
- Подписи — только реальные данные, в безопасной зоне, не на «вкусной» детали.
- Петля: последний кадр плавно переходит в первый.
- После сборки — 3–4 кадра из готового mp4; владельцу — таблица «секунды → комната/переход» и честные слабые места материала.
