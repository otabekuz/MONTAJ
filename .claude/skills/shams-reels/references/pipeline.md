# Команды, сбои и уроки

Все команды запускаются из корня репозитория `github.com/otabekuz/MONTAJ` (на компьютере владельца — `C:\Users\user\MONTAJ`).

## Содержание
1. Команды по порядку
2. Что где лежит

5. Устройство кода (если нужно менять систему)

## 1. Команды по порядку

| Команда | Что делает | Зачем |
|---|---|---|
| `npm run ingest -- "<путь>" <slug>` | видео → `public/reels/<slug>.mp4` с перекодированием; аудио (mp3/wav/m4a) копирует как есть | видео из генераторов аватара имеют нерегулярные ключевые кадры, без перекодирования рендер падает |
| `npm run transcribe -- reels/<slug>.mp4 uz` | распознаёт речь (whisper.cpp) → `public/reels/<slug>.captions.json` | даёт точные тайминги слов; первый запуск качает модель ~1,5 ГБ, запускать в фоне (~3 мин) |
| `npm run align -- reels/<slug>` | подставляет точный текст из `script.md` («Текст для генерации аватара») на тайминги Whisper | Whisper плохо пишет узбекские слова, но время знает точно; расхождение до ~25% — норма |
| `npx remotion still Reel out/<slug>-check-<n>.png --props=reels/<slug>/edit.json --frame=<n> --scale=0.5` | один кадр для проверки | увидеть каждый элемент до полного рендера |
| `npm run build-reel -- <slug>` | рендер → громкость −14 LUFS → обложка; при сбое чтения видео сам снижает число потоков; при ошибке удаляет файл | один надёжный шаг вместо трёх; печатает «Готово» только при успехе |
| `npm run finalize -- out/<slug>.mp4` | только выравнивание громкости (−14 LUFS, пик ≤ −1,5 dBTP) | если рендерили вручную |
| `npm run sfx` | пересобирает звуки в `public/sfx/` | после изменения набора звуков |
| `npm run pack-skill` | пересобирает справочники скилла из правил агентов, обновляет глобальный скилл и архив | после любой правки правил в `.claude/agents/` или этого скилла |
| `npm run dev` | Remotion Studio (композиции `Reel`, `ReelDemo`, `ReelDemoSplit`) | посмотреть элементы вживую |

Кадр для проверки ≈ секунда исходника ÷ `speed` × 30; после вырезки пауз время сдвигается, бери с запасом.

## 2. Что где лежит
- `reels/<slug>/script.md` — сценарий; `reels/<slug>/edit.json` — план монтажа (в git).
- `public/reels/<slug>.mp4|.mp3` — исходник (не в git); `public/reels/<slug>.captions.json` — субтитры; `public/reels/<slug>/` — скриншоты и B-roll.
- `out/<slug>.mp4`, `out/<slug>-cover.jpg` — результат (не в git).
- `public/sfx/` — звуки; `public/music/` — лицензионная музыка; `public/logos/` — логотипы для карточек `tool`.
- `PROGRESS.md` — журнал: статус роликов, решения владельца, уроки.

## 3. Типовые сбои

| Симптом | Причина | Что делать |
|---|---|---|
| `No frame found at position …` | видео не прошло `ingest`, либо потоки рендера мешают друг другу | `ingest`; `build-reel` сам повторит с 2 и 1 потоком |
| субтитры обрывками («Ç at G PD») или кириллицей | Whisper не знает узбекский | `npm run align`; текст в `script.md` должен совпадать с фактически озвученным |
| `align` показывает расхождение > 25% | аватар или владелец отошёл от текста | вписать в `script.md` реально произнесённый текст и повторить |
| тишина перед главной мыслью (`beats`) не слышна | говорящий не сделал паузу, музыки нет | ставить паузу в тексте для генератора; добавить музыку |
| ролик заметно длиннее сценария | аватар говорит медленно и без пауз | `speed` 1.1–1.25, вырезка пауз здесь почти не помогает |
| горизонтальный скриншот мелкий в телефоне | не тот тип рамки | `screen` с `"frame": "window"` |
| видео владельца уже «разделено» (верх пустой, спикер снизу) | снято под split заранее | перед монтажом вырезать нижнюю половину (`crop=1080:1024:0:896`) |
| команда через `python`/`python3` зависает | в системе заглушка Microsoft Store | использовать `node` |
| длинная команда с кириллицей и кавычками ломается в Git Bash | экранирование | писать файл через Write/Edit, не через heredoc |

## 4. Уроки прошлых роликов
- AI-аватар говорит ~1,8 слова/с и почти без пауз: темп задаёт `speed`, а не вырезка пауз.
- Голос из ElevenLabs идёт без пауз вовсе: `beats` не работают, длину задаёт только `speed`.
- В `script.md` в раздел «Текст для генерации аватара» вписывается **фактически озвученный** текст (числительные — как произнесены), иначе `align` расходится.
- В split кадр спикера берётся выше, чтобы над головой оставался воздух для субтитров.
- В voice пустой кадр заметен сразу: графика идёт встык, под хуком тоже стоит элемент, хук в одну строку; итоговый список (`steps`) начинать заранее.
- Владелец расширяет сценарии: ролик длиннее ~60 с хуже удерживает — говорить об этом честно.
- Скриншоты сайтов можно снять встроенным браузером; факты из сценария владельца проверять и отмечать неточности.
- Не отправлять ролик, пока сборка не напечатала «Готово».
- Ролик `dizayn-skills` (voice) — образец утверждённого стиля: объект-герой, три мира, набор текста, смаз, схема с бегущим светом. Его план — `reels/dizayn-skills/edit.json`.
- Цифры без источника («80 foiz») в графику не выносим, даже если они есть в голосе; говорим владельцу.

## 5. Устройство кода
- `src/Reel/schema.ts` — формат `edit.json` (источник истины). `src/Reel/Reel.tsx` — слои ролика.
- `src/Reel/fx/` — элементы: Title, ToolCard, ChatPrompt, Steps, BigNumber, ScreenInsert, Broll, Accent, Concept (icon), Compare, Flow, Chart, Slam, Typed, Paper, Sites (clones, morph), Hub, ProgressBar; `icons.tsx` — словарь иконок.
- `camera.ts` — смена плана, наезды, тряска, фокус; `Transitions.tsx` — переходы; `Sound.tsx` — звуки и музыка; `cuts.ts` — вырезка пауз и ускорение; `Captions.tsx` — субтитры; `Stage.tsx` — живой фон; `layout.tsx` — зоны форматов; `theme.ts` — палитра Monolith; `motion.ts` — единые кривые движения.
- Новый элемент: тип в `schema.ts` → компонент в `fx/` → ветка в `Overlays.tsx` → звук в `Sound.tsx` → описание в `.claude/agents/reel-editor.md` → `npm run pack-skill`.
