# Анимации и элементы монтажа

> Сгенерировано из `.claude/agents/reel-editor.md` командой `npm run pack-skill`. Правь источник, не этот файл.

Каталог всего, что можно поставить в ролик: элементы графики (`overlays`), переходы, звуковые акценты, приближения камеры. Точный формат полей — `schema.ts` рядом (копия `src/Reel/schema.ts`), заполненный план настоящего ролика — `example-edit.json`. Как из этого собирать ролик — `montage.md`.

## Содержание
1. Шаблон edit.json
2. Каталог элементов (overlays)
3. Переходы
4. Звуковые акценты и тишина
5. Приближения камеры

## Шаблон edit.json

```json
{
  "layout": "split",
  "videoFile": "reels/<slug>.mp4",
  "captionsFile": "reels/<slug>.captions.json",
  "fallbackSeconds": 10,
  "cutPauses": true,
  "speed": 1,
  "beats": [],
  "cues": [],
  "hook": "…",
  "hookSeconds": 2.8,
  "highlightWords": ["…"],
  "autoFraming": true,
  "zooms": [],
  "transitions": [],
  "overlays": [],
  "sfx": true,
  "musicFile": "",
  "cta": "",
  "ctaSeconds": 2.6
}
```

### Каталог элементов (`overlays`)
| type | когда | `dur`, сек |
|---|---|---|
| `title` `{text, sub}` | начало смыслового блока: 1–3 слова крупно (`text`), маленькая красная метка сверху (`sub`, напр. «01», «xato», «3 qadam») | 1.3–2.0 |
| `tool` `{name, icon}` | называют нейросеть/сервис. icon: `claude`, `chatgpt`, `gemini`, `perplexity`, `notion`, `telegram`, `instagram`, `midjourney`, `anthropic` или `file:<png в public/logos>` | 1.4–2.0 |
| `chat` `{prompt, answer}` | пример промпта; answer — 2–4 строки через `\n` | ≈ len(prompt)/34 + 1.3 + 0.2·строк + 1.5 |
| `steps` `{title, items}` | перечисление 2–4 пунктов (≤ 4 слова каждый) | ≈ 0.4 + 0.85·n + 2.0 |
| `number` `{value, suffix, label}` | **только реальная цифра из речи** | 3.0–3.5 |
| `screen` `{title, image, zoomTo?, frame?}` | демонстрация экрана; image — файл в public/ или "" (макет). `frame`: `"phone"` (по умолчанию, вертикальные скриншоты) или `"window"` (**горизонтальные** скриншоты — широкое окно, картинка целиком, макс. размер). `zoomTo {x,y,w,h}` — через 1 с наезд на область + красная рамка; для `window` это доли самого скриншота (открой картинку через Read и оцени координаты), для `phone` — доли экрана телефона. **Если на скриншоте есть конкретная фраза/кнопка/результат — всегда zoomTo**, и проверь рамку рендером кадра | 3.0–5.0 (с zoomTo ≥ 3.5) |
| `broll` `{file}` | есть видео/картинка от владельца по теме (`reels/<slug>/…`). Без файла — не используй | 2.0–4.0 |
| `accent` `{text, emoji}` | ударная фраза/вывод, 1–3 слова | 1.5–2.0 |
| `icon` `{items: [{icon, label}]}` | **визуальная метафора** мысли: 1 иконка крупно или 2–3 в ряд (напр. «vaqt, pul, natija»). Ключи icon: `time, hourglass, calendar, money, sales, growth, chart, levelup, rocket, speed, error, wrong, right, question, idea, brain, ai, magic, wand, prompt, chat, write, copy, document, checklist, target, search, filter, settings, puzzle, shuffle, key, lock, eye, person, clients, business, learn, book, phone, laptop, photo, video, voice, language, love, happy, sad` | 1.8–3.0 |
| `compare` `{bad, good, badLabel, goodLabel}` | «все делают так — а надо так», плохой/хороший промпт, до/после. Тексты ≤ 12 слов; метки обычно `Yomon`/`Yaxshi`, `Oldin`/`Keyin` | 3.5–5.0 |
| `flow` `{nodes: [{label, icon}]}` | процесс или формула из 2–4 частей (A → B → C), последний блок — результат (красный). label 1–2 слова, icon — ключ из списка выше или "" | ≈ 0.15 + 0.75·n + 1.8 |
| `chart` `{title, unit, bars: [{label, value, highlight}]}` | сравнение величин из речи — **только реальные цифры**; 2–4 столбика, `highlight: true` у главного | 3.5–4.5 |
| `typed` `{text, em}` | важная фраза **набирается по словам** со свечением; слова из `em` остаются красным курсивом с засечками (акцент голосом на экране). Для тезиса, отрицания, вывода: «Muammo AI'da emas» (em: «emas»). ≤ 5 слов | 1.5–2.6 |
| `slam` `{text, em}` | **смена мира: весь кадр красный**, одно огромное чёрное слово (≤ 9 букв) + приписка курсивом. Главный удар ролика — **ровно один раз**, на ключевом слове («PROMPT»). Свой звук-удар; `riser`-cue ставь так, чтобы он упирался в начало | 1.5–2.0 |
| `paper` `{tag, title, items: [{text, mark}]}` | **смена мира: белый бумажный бланк** с пунктами (2–5, по 1–2 слова); `mark`: `"v"` — галочка, `"x"` — зачеркнуть красным, `""` — пусто. Для перечислений «что даёт», чек-листов, «делай / не делай». `tag` — крупная метка в шапке, `title` — мелкая подпись. Не чаще 1–2 раз | ≈ 0.5 + 0.9·n + 0.8 |
| `hub` `{center, items}` | **ядро + модули**: к центральному узлу («Claude») по очереди подключаются 2–4 модуля, по линиям бежит свет. Для «N инструментов / частей / шагов, которые подключаются к одному». Названия ≤ 10 букв. Повтори в финале с настоящими названиями — рифма | ≈ 0.6 + 0.6·n + 0.8 |
| `clones` `{labels, marks?}` | три одинаковых типовых сайта (фиолетовый градиент) — «всё на одно лицо». `labels` — подписи под каждым (≤ 2 слова), `marks` — доли длительности (0..1), когда подпись появляется, чтобы попасть в слова | 3.5–7.5 |
| `morph` `{before, after}` | один типовой сайт превращается в строгий премиальный (красная линия-сканер, в середине элемента). Ставь так, чтобы середина пришлась на слова о результате | 4.0–5.5 |

**Объект-герой.** Сильный ролик — одна история с одним героем, а не «заголовок → иконка → заголовок». Выбери сущность, о которой ролик (сайт, промпт, число, чат), и проведи её через весь ролик, меняя состояние: показана проблема → ухудшение → решение → результат. Сейчас готовый герой есть для темы сайтов и дизайна (`clones` → `clones` → `morph`); для чисел — `number`/`chart`; для связки инструментов — `hub` в середине и снова в финале. Если готового героя нет — повторяй один и тот же элемент с изменением (`compare`, `flow`), и напиши в отчёте, какого героя стоит добавить в код.

**Три мира.** Чёрный с сеткой — основной. Красная заливка (`slam`) — удар, один раз. Белая бумага (`paper`) — передышка и перечисление. Смена мира = поворот в смысле; не меняй мир без причины и не ставь два «светлых» элемента подряд.

**Показывай сказанное анимацией — но смысл, а не каждое слово.** Каждая ключевая мысль (примерно раз в 3–4 с) получает визуальную метафору: сравнение → `compare`, формула/процесс → `flow`, «время/деньги/результат» → `icon`, величины → `chart`. Не иллюстрируй каждое существительное — это выглядит как детская презентация.

`at` — секунда, когда звучит ключевое слово (можно на 0.1–0.2 с раньше).

### Поля плана: что значит каждое
- Все `at` и `dur` — **секунды исходника**. При `speed` 1.15 элемент с `dur` 3.5 живёт на экране ~3 с.
- `fallbackSeconds` — длина ролика, если файла видео ещё нет (заглушка); на готовый ролик не влияет, ставь длину исходника.
- `hookSeconds` — сколько секунд исходника держится хук; обычно до конца первой фразы (2–3.5).
- `cta` — текст плашки-концовки с кодовым словом; пусто — плашки нет и `ctaSeconds` ничего не резервирует.
- `highlightWords` — сравниваются без регистра и пунктуации, целым словом: пиши словоформу так, как она стоит в субтитрах (`AI'ni`, а не `AI`).
- `zooms`: `{at, dur, scale}`; `transitions`: `{at, type}`; `cues`: `{at, sound, volume}`.
- `number.value` — число; `title.sub` и `accent.emoji` можно оставить пустой строкой. Эмодзи в `accent` — редко, один на ролик максимум: стиль Monolith строгий.
- Диапазоны `dur` в таблице — ориентир для чтения. Если фраза в речи короче — сокращай до длины фразы (но не меньше ~1.0 с) и упрощай текст элемента, а не налезай на следующий.

### Тонкости элементов
- `chat` показывает только **промпт**. Ответ нейросети в `answer` — выдумка, поэтому: либо заканчивай `chat` до появления ответа (`dur` ≈ len(prompt)/34 + 1.0, `answer` — пустая строка) и следом ставь `screen` с настоящим скриншотом, либо бери в `answer` текст дословно со скриншота владельца.
- `steps`: пункты появляются каждые 0,85 с и к словам не привязываются. Если слова в речи идут реже (> 1,2 с между пунктами) — вместо `steps` ставь отдельный `title` на каждый пункт с `sub` «01», «02»… У `steps` свой заголовок, отдельный `title` перед ним не нужен.
- `compare`: «плохая» карточка появляется сразу, перечёркивается через ~0,5 с, «хорошая» — через ~1 с. Ставь `at` так, чтобы слова про «хорошее» звучали не раньше чем через 1 с; иначе раздели на два элемента.
- Устный призыв без кодового слова («Saqlab qo'ying») можно поддержать `accent` или `icon` с этим текстом; плашка `cta` — только для кодового слова.

### Переходы (`transitions`) — на границах смысловых блоков
- `whip` — пролёт, универсальный;
- `wipe` — шторка, перед блоком ценности/шагов;
- `flash` — вспышка на «раскрытии» (цифра, результат, вывод);
- `glitch` — максимум 1 на ролик, для tech-момента;
- `smear` — **смаз**: полосы света пролетают через кадр. Основной переход между блоками (вместо убранного «вжуха»), мягче остальных — можно 3–5 на ролик.
Ориентир — один переход на 8–10 с ролика (3–5 на 30–45 с, 2–3 на 20–25 с). `whip` не ставь ближе 0.5 с к началу `accent`: пролёт камеры и тряска удара спорят друг с другом; `flash` и `glitch` вместе с `accent` допустимы. В split переходы идут только в верхней половине.

### Звуковые акценты (`cues`) и тишина (`beats`)
- `cues: [{at, sound, volume}]` — `riser` **заканчивается** в `at` (нарастание упирается в момент), остальные (`impact`, `shine`, `glitch`, `pop`; **whoosh не используем** — владелец убрал) стартуют в `at`. Громкость 0.25–0.45. Графика и переходы уже озвучены сами — cues только для драматургии:
  - `riser` → в кульминацию (главный вывод, `accent`, `number`) — 1 раз на ролик;
  - `impact` на самом сильном слове без графики — максимум 1–2.
- `beats: [сек]` — «тишина перед главной мыслью»: пауза перед этим словом не вырезается (до 0.7 с), музыка в ней затихает. **0–1 раз на ролик**, только перед ключевым выводом. Во время тишины — никаких звуков и новых элементов; сразу после — `accent` или `title`.

### Приближения (`zooms`)
`autoFraming: true` уже меняет план на каждой фразе. Явные `zooms` (scale 1.1–1.2, dur 0.8–1.5) — только на 1–3 самых сильных словах.
