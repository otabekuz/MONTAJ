## Что делать в новом чате
1. Запустить скилл `montaj-reels` (он сам читает `PROGRESS.md`), затем прочитать `references/style.md`, `references/tour.md`,
   `references/ai-angles.md`, `docs/tour-reference.md`.
2. Посмотреть, что лежит в папке владельца. Если это **образцы стиля** — разобрать так же, как в `docs/tour-reference.md`,
   и дополнить `style.md`. Если это **материал объекта** — путь «Обзор» (§2а скилла) или «Монтаж» (§2, если владелец в кадре).
3. Папка с кириллицей и пробелами: ffmpeg Remotion из PowerShell на таких путях падает — **сначала скопировать файлы
   в латинский путь** (`out\src\<slug>\`), потом `tour-ingest` / `ingest` (урок в `PROGRESS.md`).
4. Порядок «идеально»: разбор материала (`tour-scan` + листы кадров глазами) → честный список неудачных мест → вопросы владельцу
   одним AskUserQuestion → план монтажа → **самопроверка плана** (`npm run check -- <slug> 0.3s t1 t2 … c1 c2 …` и чек-листы
   `style.md` §4 и `tour.md` §6) → исправить → сборка → кадры из готового mp4 → отправка с таблицей «секунды → что происходит».
5. Нехватка ракурсов → `ai-angles.md`: раскадровка, промпты и цена — **на «да» владельца**, только потом Wan 3.0 (Higgsfield).
6. После каждого шага — `PROGRESS.md` и `git push`.
