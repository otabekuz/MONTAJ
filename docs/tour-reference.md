# Новый стиль: обзор объекта «одним дублем» — разбор референсов

Владелец прислал 4 ролика-образца (2026-10-19). Разбор сделан покадрово: кадры каждые 0,07–0,33 с,
оптический поток (скорость и направление движения камеры по кадрам), спектр и темп музыки.
По этому разбору сделан формат **Tour** (`src/Tour/`) и правила `.claude/skills/montaj-reels/references/tour.md`.

| | Длина | Что это | Темп музыки |
|---|---|---|---|
| A | 13,3 с | одна гостиная, медленный облёт вокруг стола | ~92 BPM, ровный бит |
| B | 7,8 с | гостиная → кухня, плавные куски + 3 резких поворота | атмосферный пэд без бочки |
| C | 43 с | вся квартира пешком, 12 комнат и проходов | ~139 BPM (R&B/хип-хоп) |
| D | 9,0 с | вся квартира быстро, нарастание → «дроп» на 3,1 с | ~108 BPM, нарастание |

## Общее у всех четырёх
1. **Объектив 0.5x (сверхширокий), вертикально, камера на уровне груди**, чуть смотрит вверх — в кадре потолок
   с линиями света. Линии подсветки и плинтусов работают как направляющие, тянут взгляд в глубину.
2. **Кадр не стоит ни секунды.** Каждый кадр — движение: облёт вокруг мебели, проход вперёд, поворот.
   Ни одного статичного плана со штатива.
3. **Плавность стабилизатора** (подвес или режим «Экшн»), шаг медленный; энергию добавляют не ногами, а монтажом —
   ускорениями (speed ramp).
4. **Склейки спрятаны в движении** — зритель видит «один проход по квартире»:
   - **резкий поворот (whip)** — камера резко поворачивает, кадр смазывается, под смазом — склейка (B 2,2–2,8 с; D 1,3–1,8 с);
   - **наплыв в движении** — два кадра, движущиеся в одну сторону, полсекунды просвечивают друг через друга
     (C 7,3–7,9 с гостиная → кухня; C 15,8–16,5 с; C 37,4–37,9 с; A 10,3–10,6 с);
   - **шторка-предмет** — дверь, стена, колонна, торшер проходят у самого объектива и закрывают кадр
     (C 21,0–21,7 с коричневая дверь; D 6,6 с белая дверь; D 8,1 с угол стены; A 2,3–4,7 с торшер на переднем плане);
   - **пролёт** — наезд в дверной проём или стену, из него появляется новая комната (D 3,6–4,3 с — ровно на «дроп» музыки);
   - **склейка по движению** — встык, но движение до и после совпадает по направлению и скорости (C 29,1 с).
5. **Скорость меняется плавно, а не рывком**: на «вкусном» (люстра, вид из окна, кровать, мрамор) — ~1×,
   между комнатами — 2–5× с естественным смазом. Разгон и торможение растянуты на 0,3–0,5 с.
6. **Свет**: включены все лампы и подсветка, шторы открыты, экспозиция светлая, белое — белое.
   Цвет нейтральный, чуть контраста, без тяжёлых фильтров и без виньетки.
7. **Только музыка**: ни голоса, ни текста, ни логотипа. Склейки и повороты — на удары, главный «пролёт» — на дроп (D).
8. **Начало — сразу в движении на самом эффектном общем плане** (гостиная, люстра). Первый кадр уже едет.
9. **Конец закольцован или «закрыт»**: D заканчивается наездом в стену, а начинается выходом из-за стены —
   при повторе Reels стык незаметен; C заканчивается закрывающейся дверью.

## Ролик A — облёт гостиной (13,3 с)
- 0–5 с: облёт по дуге вокруг журнального столика, скорость плавно растёт (поток 0,6 → 1,6 px/кадр);
  2,3–4,7 с торшер проходит на переднем плане — объём, «дорогой» параллакс.
- 5–10 с: камера проходит к ТВ-стене, растение на переднем плане.
- 10,3–10,6 с: наплыв в движении на обратную точку той же комнаты.
- 10,6–13,3 с: общий план гостиной, движение замедляется к концу — «посадка» кадра.
- Урок: одна комната может держать 13 с, если кадр всё время меняет глубину (передний план → дальний).

## Ролик B — «поворотами» (7,8 с)
- 0–1,2 с: начало посреди движения — камера «падает» из наклона потолка на гостиную (хук: движение с 1-го кадра).
- 1,2–2,2 с: медленно, 1×. 2,2–2,8 с: поворот вправо со смазом (скорость ×5) → ТВ-стена.
- 3,0–4,0 с: медленно. 4,0–4,3 с: поворот → коридор и столовая. 5,6–5,9 с: поворот → кухонный остров.
- 6,0–7,8 с: торможение на кухне.
- Урок: схема «медленно 1–1,5 с → поворот 0,2–0,3 с» — и короткий ролик выглядит как дорогой проход по всей квартире.
  Все повороты в **одну сторону** — ощущение непрерывного движения.

## Ролик C — полный проход (43 с)
| Время | Что | Переход |
|---|---|---|
| 0–7 с | гостиная и столовая, облёт вокруг стола | наплыв 7,3–7,9 с |
| 8–11 с | кухня-остров, проход вдоль | проход в коридор |
| 11,5–15,5 с | коридор, консоль с зеркалом | наплыв сквозь дверь 15,8–16,5 с |
| 16,5–21 с | гостевой санузел, зеркало с подсветкой | дверь у объектива 21,0–21,7 с |
| 22–25 с | коридор | вход в спальню |
| 25,3–28,5 с | спальня | дверь + склейка по движению 29,1 с |
| 29,2–33 с | спальня с видом, кровать | поворот к гардеробной |
| 33–37 с | гардеробная со стеклом | поворот + наплыв 37,4–37,9 с |
| 38–41 с | душ, мрамор, раковина | — |
| 41–43 с | финал на закрывающейся двери | конец |
- Порядок комнат — **как идёт гость**: гостиная (самое эффектное) → кухня → коридор → санузел → спальни → гардероб → ванная.
- Ошибка в образце: **в стекле гардеробной на 37,4–37,7 с отражается оператор**. Такое вырезаем или прячем в наплыв.

## Ролик D — быстрый тизер (9 с)
- Музыка 0–3,1 с — нарастание, на 3,1 с — дроп (входит бас).
- Повороты со смазом каждые ~1,2 с: 1,3–1,8 с (гостиная → кухня), 2,4–2,9 с (кухня).
- 3,6–4,3 с: пролёт в дверь спальни **точно на дроп** — главный момент ролика.
- 6,0–6,5 с: поворот из спальни к двери; 6,6–7,0 с: белая дверь проходит у объектива — склейка спрятана.
- 8,1–8,7 с: угол стены → наезд на диван → в стену. Ролик кончается стеной, начинается выходом из-за стены — петля.
- Урок: в быстром тизере кадр держится 0,6–1,5 с, переход — каждые 1–2 удара.

## Что взято из практики монтажа недвижимости
- Музыку выбирают **до** монтажа: её бит задаёт длину кадров ([HomeJab](https://homejab.com/10-video-editing-tips-for-real-estate-tours/)).
- Кадр — до ~3 с; проходные места ускорять, главные (кухня, вид) — замедлять ([HomeJab](https://homejab.com/10-video-editing-tips-for-real-estate-tours/)).
- Для Reels — 15–30 с: важен досмотр ([shhots](https://shhots.ai/blog/real-estate-reels-ideas/)); вертикаль снимать сразу вертикально ([async](https://async.com/blog/real-estate-video-editing/)).
- Для ускорений снимать 60 к/с ([Imagen](https://imagen-ai.com/post/real-estate-video-editing/)).
- Резкий поворот работает, только если оба поворота в одну сторону и с одной скоростью ([No Film School](https://nofilmschool.com/how-to-do-a-whip-pan)); невидимая склейка — через затемнение или предмет, закрывающий кадр ([Motion Array](https://motionarray.com/learn/filmmaking/in-camera-transitions/)).
