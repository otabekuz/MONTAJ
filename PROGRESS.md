## Принятые решения
- Субтитры — по образцу `docs/subtitle-style-reference.png`: белый жирный Inter Tight, две строки по центру
  (короткая сверху, главное слово крупно снизу), фраза появляется целиком, звучащее слово чуть крупнее,
  ключевые слова — светлым акцентом. Крупные цифры — «металлом» в цвет палитры.
- Цвета — светлые и приятные: один светлый акцент на тёмном фоне, не больше ~10% кадра.
- Во время `slam` субтитры скрываются (на светлой заливке белый текст не читается).
- Герои для недвижимости: объявление (`clones` → `morph`), объект (`property`), район (`location`), цена (`number`).
- Звуки синтезированы свои (`npm run sfx`), whoosh не используем.
- Стиль субтитров «за спиной» (3 уровня, гигант за спиной) называется **«Серебро»** (`captionStyle: "layered"`); второй стиль — **«Классика»** (`classic`).
- **Перед каждым монтажом спрашивать владельца**: метод монтажа (full / split / voice) и стиль субтитров (Серебро / Классика), плюс язык, если неизвестен. Решение владельца 2026-10-05.
- **Фирменный стиль = сильное из всех 7 образцов** (решение владельца 2026-10-19), `references/style.md`. Недостающие ракурсы —
  догенерация из настоящих фото через Wan 3.0, **только после раскадровки и «да» владельца**; ничего не приукрашивать.
- **Новый стиль обзоров** (образцы владельца 2026-10-19): 0.5x, кадр всегда в движении, ускорения между комнатами,
  склейки спрятаны, только музыка в бит, без текста по умолчанию. Перед монтажом обзора спрашивать темп (тизер / полный),
  музыку и текст (без / подписи / + плашка). Материал владельца сначала разбирать (`tour-scan`) и честно называть неудачные места.
- Карта районов Ташкента (`districts`) — схематичная, с честной пометкой «схема районов»; районы подсвечиваются по словам.

## Уроки (облако)
- ffmpeg из Remotion без фильтров `fps`/`tile`/`drawtext` и без формата `rawvideo`: частота — `-r`, кадры — `image2pipe`.
- В облаке рендер: `REMOTION_BROWSER_EXECUTABLE=/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell`.

## Уроки (компьютер владельца, Windows)
- `matte` в VP8 давал серые блоки на лице и руках при движении → переведён на VP9 (`scripts/matte.mjs`).
- Remotion-ffmpeg/ffprobe на этом ПК изредка падает с 0xC0000005 — просто повторить команду.
- Упавший `check` оставляет процессы `chrome-headless-shell` → следующий запуск: «Failed to launch the browser process». Завершить процессы из `node_modules\.remotion`. `check` теперь открывает один браузер на все кадры.
- В PowerShell аргументы `check` с `@` брать в кавычки: `'@1.5'`.
- Пересчёт частоты звука (`-ar`/`-ac`, 44,1 → 48 кГц — звук iPhone) роняет Remotion-ffmpeg **всегда** (0xC0000005).
  `ingest`, `transcribe`, `finalize` пересчитывают фильтром `aresample`; звуки `public/sfx/` пересобраны в 48 кГц (`npm run sfx`).
  `build-reel` при 0xC0000005 сам повторяет рендер.
- Пути с кириллицей (`Desktop\МОНТАЖ\…`) ломают запуск ffmpeg из PowerShell — сначала копировать видео в латинский путь (`out\src\`).
- Whisper turbo по-узбекски отдаёт **слоги** («V ah k ut un…»), но время у них верное: склеить в слова по тексту владельца
  и сверить с паузами (`silencedetect` порог −22 дБ — на улице фон шумит).
- Скриншоты с телефона лучше компьютерных: крупнее и в пропорциях кадра. `screen` с `frame: phone` теперь в пропорциях iPhone (9 : 19,5), `zoomTo` — доли самого скриншота; сдвиг при наезде ограничен краями.
- Скриншоты Telegram Desktop: обрезать боковую панель папок и полоску плеера сверху (там название аудиофайла, напр. «ElevenLabs_…»). Мелкий текст скриншота читается только с наездом `zoomTo` шириной ≤ 0,5.
- `npm run matte` через конвейер PowerShell (`| Select-Object`) зависал без нагрузки — запускать `node scripts/matte.mjs <slug>` напрямую.
- 2026-10-21: Windows периодически запрещает запуск программ (EPERM / «Отказано в доступе») — git, node, npm, PowerShell; у git —
  «failed to restrict file handles (5)», и при `git push` не стартует менеджер паролей (git спрашивает Username). Перезапуск приложения
  не помог. Смотреть журнал защиты Windows / Smart App Control / контролируемый доступ к папкам.
  Обход: ffmpeg вызывать прямо из PowerShell (`out\frames.ps1` — кадры 2 в секунду, каждое видео с повторами до 8 раз);
  у запуска через node ffprobe получает `spawn EPERM`, а у прямого — иногда испорченную командную строку (свой путь вместо файла).
  Сверка AI-видео без запуска программ: открыть mp4 по ссылке Higgsfield во встроенном браузере, кадры нарисовать на canvas, снять скриншот.
  **Причина найдена: 360 Total Security** (Smart App Control выключен). Решение: в «Белый список» 360 — папка MONTAJ, node.exe, git,
  cmd.exe, powershell.exe и сам claude.exe, затем перезапуск приложения. Даже после этого инструменты Bash/PowerShell сессии Claude
  блокируются — команды запускать во вкладке терминала приложения (run_in_terminal): там node, ffmpeg, Remotion работают.
  `esbuild.exe` и ffprobe Remotion (0xC0000005 на временной копии клипа) всё ещё изредка падают — повторять; `check` теперь сам
  повторяет кадр до 4 раз.
- Tour: «пролёт» (`push`) на неподвижном фото даёт ступенчатые копии кадра (смаз склеивает 2–5 одинаковых кадров с разным масштабом) —
  на фото-клипах `push` не ставить, только на видео; на фото — `wall`/`whip`/`dissolve`.
- Надпись `surface` нужна на большой ровной поверхности ≥ 40% ширины кадра (входная дверь анфас); узкая дверь в перспективе — мелко и криво.
- Финальная плашка Tour на светлом фоне не читалась — затемнение снизу усилено (0,7 до половины высоты) в `src/Tour/Text.tsx`.
- Фото владельца (Telegram, 720×1280) как клипы: ffmpeg `-loop 1 -i фото -t 3 -r 30` → в папку с клипами → `tour-ingest`
  (скрипты сессии лежали в `out\`, в git не попадают).
- **Сборка на ПК владельца — `node scripts/build-reel.mjs <slug> --chunks`**: целиком рендер Remotion падает почти всегда
  (0xC0000005 у ffprobe, «No frame found», «Request closed» — разные клипы каждый раз), поэтому рендер кусками по 4 с:
  упавший кусок повторяется (до 6 раз), готовые куски переживают перезапуск, звук Tour делается ffmpeg напрямую
  (рендер звука Remotion зависал), склейка `concat -c copy`. ~5 мин на кусок, ролик 30 с — ~40 мин.
  В ffmpeg Remotion нет `afade` и муксера m4a — затухание формулой в `volume`, звук в `.mp4`.
- Вкладка терминала после упавшей сборки может считаться занятой (висит дочерний процесс) — открывать новую вкладку.
- `build-reel --chunks`: кусок дольше 6 мин отменяется и повторяется (зависания после сбоя чтения кадра), шаги ffmpeg
  (звук, склейка, громкость) повторяются при 0xC0000005. Сильные разгоны (4–5× со смазом) читают больше кадров — сбоев больше.
