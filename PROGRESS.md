## Принятые решения
- Субтитры — по образцу `docs/subtitle-style-reference.png`: белый жирный Inter Tight, две строки по центру
  (короткая сверху, главное слово крупно снизу), фраза появляется целиком, звучащее слово чуть крупнее,
  ключевые слова — светлым акцентом. Крупные цифры — «металлом» в цвет палитры.
- Цвета — светлые и приятные: один светлый акцент на тёмном фоне, не больше ~10% кадра.
- Во время `slam` субтитры скрываются (на светлой заливке белый текст не читается).
- Герои для недвижимости: объявление (`clones` → `morph`), объект (`property`), район (`location`), цена (`number`).
- Звуки синтезированы свои (`npm run sfx`), whoosh не используем.
- Стиль субтитров «за спиной» (3 уровня, гигант за спиной) называется **«Серебро»** (`captionStyle: "layered"`); второй стиль — **«Классика»** (`classic`).
- **Перед каждым монтажом спрашивать владельца**: метод монтажа (full / split / voice) и стиль субтитров (Серебро / Классика), плюс язык, если неизвестен. Решение владельца 2026-10-05.
- Карта районов Ташкента (`districts`) — схематичная, с честной пометкой «схема районов»; районы подсвечиваются по словам.
